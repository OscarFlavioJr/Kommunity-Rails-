# Kommunity

**Eventos simples. Conexões reais.**

Kommunity é uma plataforma de eventos sociais criada para tornar o processo de criação, convite e gestão de eventos o mais simples, rápido e acessível possível.

Inicialmente totalmente gratuita, a aplicação funciona como um **PWA (Progressive Web App)**, permitindo acesso em qualquer dispositivo diretamente pelo navegador — sem necessidade de instalação.

---

## Visão

Reduzir o atrito entre pessoas e encontros.

O Kommunity nasce com um propósito claro: eliminar burocracia, complexidade e fricção no processo de organizar eventos sociais. Criar um evento deve ser tão simples quanto enviar uma mensagem.

---

## Proposta de Valor

- Criação rápida de eventos
- Convites simples e diretos
- Gestão de participantes em tempo real
- Acesso multiplataforma
- Sem downloads
- Sem formulários longos
- Sem complexidade desnecessária

---

## Funcionalidades (MVP)

- Criar eventos sociais
- Gerar links de convite
- Confirmação de presença
- Lista de participantes
- Compartilhamento rápido
- Interface simples e intuitiva
- Funcionamento como PWA
